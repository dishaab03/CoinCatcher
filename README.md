# 2D Coin Catcher

A 2D game developed using Unity and C#.

## Features
- Catch falling coins to increase your score.
- Avoid bombs to protect your lives.
- Track coins and remaining lives.

## Technologies
- Unity 6
- C#
- Git and GitHub

## How to Run
1. Clone or download this repository.
2. Open the project using Unity Hub.
3. Open the game scene.
4. Press Play to start playing.
